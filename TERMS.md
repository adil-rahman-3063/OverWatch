## 2. Description of Software & System Scope

OverWatch is an open-source development companion and physical approval gatekeeper designed to provide:
1. **Autonomous AI Interlock**: A hardware-tokenized approval pipeline that intercepts terminal commands (`run_command`) generated by autonomous AI coding assistants (such as Google Antigravity and Claude Code) via local pre-tool hooks, streaming the proposed command to a paired mobile device for explicit human authorization.
2. **StandBy Desk Deck**: An OLED-optimized touch interface providing mechanical 3D split-flap timekeeping, real-time Windows hardware telemetry (CPU, RAM, GPU), and multi-session Windows GSMTC media playback control.
3. **Bidirectional Image & Clipboard Beaming**: Instant streaming of images between a paired mobile device and the Windows OS Clipboard (`Ctrl+V` ready) and disk storage (`Pictures/OverWatch/`), as well as full-resolution desktop screen capture.
