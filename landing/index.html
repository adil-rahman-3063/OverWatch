Open-Source PhoneBox Alternative / AI Hardware Interlock / OLED StandBy Desk Deck (v1.2.0)

The Physical AI Interlock For Coding Agents

OverWatch is an open-source PhoneBox alternative that turns an idle smartphone on your desk into a dedicated OLED hardware interlock and StandBy companion. It intercepts terminal tool calls on local loopback port 49152 with sub-5ms latency, enforces a strict 20-second fail-closed security boundary, and controls workstation media and clipboard.

Definition: What is an AI Hardware Interlock?

An AI hardware interlock is an out-of-band physical security token that isolates autonomous agent authorization from the primary computer screen. By intercepting PreToolUse hooks over local loopback IPC (127.0.0.1:49152) and streaming approval prompts to an external OLED desk deck, it guarantees commands fail closed on timeout or disconnect without desktop popup fatigue.

  2. Screen 02: AI Mission Control & Hardware Interlock - Live agent session status (model, tokens, goal, active tool), audible approval chime, and 1-tap Allow/Deny buttons.
  3. Screen 03: Windows GSMTC Media & Telemetry - Native Windows media transport controls scoped to active session indices (Spotify, YouTube Music) and live CPU/RAM gauges.
  4. Screen 04: Workstation Macros & Universal Clipboard Beam - Bi-directional text and image beaming between smartphone and Windows PC with 1-tap lock and terminal launch shortcuts.

Frequently Asked Questions (FAQ)

Is OverWatch an open-source alternative to PhoneBox?

Yes. OverWatch is a purpose-built, fail-closed open-source PhoneBox alternative (ersinkoc/phonebox). While PhoneBox provides an Android monitor for Claude Code approvals and quotas, OverWatch expands this into a full physical AI security interlock on local loopback port 49152 with sub-5ms latency, native WinRT media controls, bi-directional Windows clipboard sync, 4 dedicated OLED StandBy surfaces, and support for both Google Antigravity and Claude Code.

What happens if my phone battery dies or Wi-Fi drops?

OverWatch operates on a strict fail-closed security law. If the companion phone is offline, disconnected, or unanswered for 20 seconds, the local IPC hook immediately responds with decision: deny, safely terminating terminal execution.

Does OverWatch send my source code or terminal commands to cloud databases?

No. OverWatch uses an ephemeral, broadcast-only Supabase Realtime WebSocket channel (overwatch:{device_id}). Payloads exist in volatile memory only during the active approval window and are purged immediately upon decision. Zero code is logged to disk in the cloud.

Which AI coding agents and CLI tools are supported?

Native support is provided for Google Antigravity (via Auto mode permissions) and Claude Code CLI. Any autonomous agent supporting stdin/stdout JSON lifecycle hooks can integrate directly with the local IPC server.
