## 1. Zero Tracking & No Cookies

The OverWatch public landing page and interactive showcase simulator ([overwatch.adilrahman.cc](https://overwatch.adilrahman.cc)) is built on a strict privacy-first foundation:
* **No Analytics SDKs:** We do not include Google Analytics, Meta Pixel, PostHog, Hotjar, or third-party user profiling scripts.
* **No Tracking Cookies:** The site does not set tracking, marketing, or behavioral cookies.
* **No Telemetry Selling:** We do not collect, aggregate, or monetize visitor information.

## 2. Interactive Live Deck Simulator

The landing page features an embedded, interactive 1:1 simulator of the OverWatch StandBy Deck:
* **Client-Side Only:** All interactions in the simulator (such as testing the mechanical 3D flip clock, testing track controls, or simulating the Gatekeeper approval modal) execute **100% locally in your browser memory**.
* **Zero Workstation Connection:** The demo simulator does not connect to your personal workstation or execute real shell commands. It is a visual showcase.
* **Simulated Web Audio:** Sound effects (mechanical click and approval chime) are synthesized directly in browser memory using the Web Audio API without network audio streams.
